## 1. Why V0.8 exists

V0.7 completed the decision engine's legal action space (4 trades), reachable player universe, past-round forward replay, and multi-round sequential decision simulation with telescoping regret attribution. However, two fundamental limitations remain:

1. **Synthetic Replay Fixtures**: V0.7 evaluated models against deterministic synthetic fixtures. V0.8 grounds the evaluation laboratory and feature store in **verified real-world historical box scores** from official feeds covering all completed seasons from `2022-23` through `2025-26`.
2. **Context-Blind Scoring**: Prior versions treated expected fantasy points ($\text{xP}$) as static player averages without modeling European basketball realities:
   - **Ruthless Blowout Benches**: In European basketball, a 15+ point 3rd-quarter lead leads coaches to bench primary stars for the entire 4th quarter, severely cutting fantasy ceiling.
   - **Foul Trouble Fragility**: With 10-minute quarters and a 5-foul limit, high-foul-rate centers face dramatic minutes and scoring truncations.
   - **Domestic League Congestion**: Weekend domestic fixtures (ACB, BSL, Greek Basket League, Lega Basket, ABA) preceding midweek EuroLeague double-round weeks (DRW) induce minutes management and fatigue.
   - **Injury Vacancy Surges**: When a primary ball-handler or high-usage starter is out, backup players absorb major usage, minutes, and assist/rebound volume.
   - **Rank-Aware Game Theory (Core / Shield / Sword)**: In fantasy leagues, leading a competition requires defensive protection (Shielding against consensus high-ownership picks), while chasing leaderboards requires high-ceiling low-ownership differentials (Swords).

---

## 2. Core Principles

1. **Ground Truth from Official Feeds**: Historical box scores, minutes, PIR, and game quarters are ingested directly from official IncrowdSports v2 feeds (`feeds.incrowdsports.com/v2`), never fabricated.
2. **Strict Offline Test Invariant (F6)**: Pytest suites execute 100% offline using committed SQLite reference fixtures; no network calls in automated testing.
3. **Multi-Competition Parity**: Every schema, ingestion pipeline, rotation model, and contextual metric supports both EuroLeague (`E`) and EuroCup (`U`).
4. **Separation of Fact vs Context Prediction**: Verified historical stats (minutes played, actual fouls, starting status) are facts; projected minutes distributions and blowout probabilities are models. They are stored in separate schemas.
5. **Human-in-the-Loop Transparency**: All rotation discounts, injury surges, and Core/Shield/Sword classifications must be transparently displayed with clear rationales in both CLI and Web Workstation.

## 4. W1 — Real Historical Box-Score Connector & Storage

### 4.1 Feed Endpoints
Target IncrowdSports v2 endpoints:
- Schedule & Games: `GET /competitions/{competition_code}/seasons/{season_code}/games`
  - Paginated (`pageSize=50`), returns game code, round, date, teams, scores by quarter (`q1`, `q2`, `q3`, `q4`, `ot1..5`), coaches, attendance.
- Game Detailed Stats: `GET /competitions/{competition_code}/seasons/{season_code}/games/{game_code}/stats`
  - Returns `local` and `road` teams with coach info, team totals, and full player box scores:
    - Identity: `player.person.name`, `player.person.code`, `player.externalId`, `player.positionName`, `player.club.code`.
    - Participation: `stats.timePlayed` (seconds), `stats.startFive` (boolean starter status), `stats.dorsal`.
    - Box score: `stats.points`, `fieldGoalsMade2`/`Attempted2`, `fieldGoalsMade3`/`Attempted3`, `freeThrowsMade`/`Attempted`, `totalRebounds`, `defensiveRebounds`, `offensiveRebounds`, `assistances`, `steals`, `turnovers`, `blocksFavour`, `blocksAgainst`, `foulsCommited`, `foulsReceived`, `plusMinus`.
    - Fantasy Target: `stats.valuation` (official PIR).

### 4.2 Database Schemas (`historical_games` & `historical_boxscores`)
```sql
CREATE TABLE IF NOT EXISTS historical_games (
    game_code INTEGER NOT NULL,
    competition_code TEXT NOT NULL,
    season_code TEXT NOT NULL,
    round_number INTEGER NOT NULL,
    game_date TEXT NOT NULL,
    home_team_code TEXT NOT NULL,
    away_team_code TEXT NOT NULL,
    home_score INTEGER NOT NULL,
    away_score INTEGER NOT NULL,
    margin INTEGER NOT NULL,
    home_q1 INTEGER, home_q2 INTEGER, home_q3 INTEGER, home_q4 INTEGER,
    away_q1 INTEGER, away_q2 INTEGER, away_q3 INTEGER, away_q4 INTEGER,
    home_coach TEXT,
    away_coach TEXT,
    PRIMARY KEY (competition_code, season_code, game_code)
);

CREATE TABLE IF NOT EXISTS historical_boxscores (
    game_code INTEGER NOT NULL,
    competition_code TEXT NOT NULL,
    season_code TEXT NOT NULL,
    round_number INTEGER NOT NULL,
    player_id INTEGER NOT NULL,
    person_code TEXT NOT NULL,
    player_name TEXT NOT NULL,
    team_code TEXT NOT NULL,
    opponent_code TEXT NOT NULL,
    is_starter INTEGER NOT NULL,
    seconds_played REAL NOT NULL,
    minutes REAL NOT NULL,
    points INTEGER NOT NULL,
    rebounds INTEGER NOT NULL,
    offensive_rebounds INTEGER NOT NULL,
    defensive_rebounds INTEGER NOT NULL,
    assists INTEGER NOT NULL,
    steals INTEGER NOT NULL,
    turnovers INTEGER NOT NULL,
    blocks INTEGER NOT NULL,
    fouls_committed INTEGER NOT NULL,
    fouls_drawn INTEGER NOT NULL,
    fg2_made INTEGER NOT NULL,
    fg2_attempted INTEGER NOT NULL,
    fg3_made INTEGER NOT NULL,
    fg3_attempted INTEGER NOT NULL,
    ft_made INTEGER NOT NULL,
    ft_attempted INTEGER NOT NULL,
    plus_minus INTEGER NOT NULL,
    pir REAL NOT NULL,
    fantasy_points REAL NOT NULL,
    team_won INTEGER NOT NULL,
    PRIMARY KEY (competition_code, season_code, game_code, player_id)
);
```

## 7. W4 — Rank-Aware Decisions & Ownership Profiling

1. **Archetype Classification**:
   - **Core**: Ownership $\ge 40\%$, low variance, high floor.
   - **Shield**: Moderate-to-high ownership, defensive protection.
   - **Sword**: Ownership $\le 15\%$, high ceiling differential.
2. **Strategy Presets**:
   - **Rank Protect**: Forces Core/Shield picks into suggestions.
   - **Balanced Value**: Unconstrained xP maximization.
   - **Rank Chase**: Boosts Sword differentials to climb rank.
