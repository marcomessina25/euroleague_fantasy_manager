## 0. Ground rules

### 0.1 Scope
- **In scope:** all 129 findings, the test and CI infrastructure needed to verify them, and doc/version sync.
- **Out of scope:** new user-facing features. Exception: the minimum needed to make an existing claim true (e.g. real live model routing, official rules ingestion).

### 0.2 Way of working (applies to every task)
1. **Red:** write the test named in the task, under `tests/test_v102_<area>.py`. Run it and confirm it fails for the reason stated in the finding.
2. **Green:** make the smallest change that fixes the root cause. No `except Exception: pass`; log or re-raise with context.
3. **Refactor**, only inside the files the task names.
4. **Verify:** the new test plus the area's existing test files, then `node --check app.js` if JS changed.
5. **Commit** one task per commit: `fix(v102/<task-id>): <summary>`, with the finding IDs in the body and the `Co-authored-by` trailer.
6. Run the full suite at the end of every phase. Phase 0 makes that trustworthy.

**Execution model (per the user workflow):**
- Opus orchestrates.
- Each task goes to a Sonnet implementer subagent (TDD), then a spec-compliance reviewer, then the code-quality reviewer.
- Doc-only tasks (P9) go to Haiku.
- Opus does the final consolidated review per phase.

### 0.3 Decisions (made here so implementation is not blocked)

| ID | Decision | Rationale |

## 3. Phase P2 — Team state: transactions, replay, validation (W3)

### P2.1 Unit of work on the shared SQLite file — STATE-1, STATE-5, ISO-1, CONC-1
- **`TeamStore.transaction()`:**
  ```python
  @contextmanager
  def transaction(self) -> Iterator[sqlite3.Connection]:
      conn = self._get_connection()
      try:
          conn.execute("BEGIN IMMEDIATE")
          yield conn
          conn.commit()
      except BaseException:
          conn.rollback()
          raise
      finally:
          conn.close()
  ```
  - Every store method gains an optional `conn` parameter. The `_save_squad_conn` / `_get_squad_conn` pattern is already half there.
- **The same `conn` is accepted by** `DecisionStore` / `DecisionLogger` writes (`tracking/store.py`), so the trade, replay, checkpoints and audit record share one transaction (D6).
- **Connection settings, in one helper used by every store:**
  - `PRAGMA journal_mode=WAL`
  - `PRAGMA busy_timeout=30000`
  - `PRAGMA foreign_keys=ON`
  - Always closed via `contextlib.closing`. Currently `with conn` commits but never closes.
- **Team creation (ISO-1):** count + insert inside `BEGIN IMMEDIATE`, plus `CREATE UNIQUE INDEX one_active_team ON managed_teams(is_active) WHERE is_active = 1`.
- **Lost updates (CONC-1):** `update_team` becomes compare-and-set on `updated_at`. On a conflict it raises `ConcurrentModificationError`; the API maps that to 409.
- **Tests (`tests/test_v102_team_state.py`):**
  - Rollback: inject an exception after the audit write (monkeypatch `DecisionLogger.log_transfer_decision` to raise). The team row, squads, checkpoints, transfers and decisions are byte-identical to before. Snapshot all five tables, then compare.
  - Concurrency: 8 threads × 30 trials of `create_team` → never more than 6 teams, never more than 1 active team. Use `threading.Barrier` so they start together.
  - Two `update_team` calls from the same stale read → the second raises.

### P5.1 Same-origin, JSON-only, Host-pinned server — WEB-1, WEB-10 (headers)
- In `web/app.py`:
  ```python
  from starlette.middleware.trustedhost import TrustedHostMiddleware
  app.add_middleware(TrustedHostMiddleware, allowed_hosts=["127.0.0.1", "localhost", "[::1]", "testserver"])

  @app.middleware("http")
  async def same_origin_json_only(request, call_next):
      if request.method in {"POST", "PUT", "PATCH", "DELETE"}:
          origin = request.headers.get("origin")
          if origin and urlsplit(origin).netloc != request.headers.get("host"):
              return JSONResponse({"detail": "Cross-origin request rejected."}, status_code=403)
          if not request.headers.get("content-type", "").startswith("application/json"):
              return JSONResponse({"detail": "Content-Type must be application/json."}, status_code=415)
      response = await call_next(request)
      response.headers.update({
          "Content-Security-Policy": "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; frame-ancestors 'none'",
          "X-Content-Type-Options": "nosniff", "X-Frame-Options": "DENY", "Referrer-Policy": "no-referrer"})
  ```

## 12. Risks of this plan and mitigations

| Risk | Mitigation |
|---|---|
| **P3.5 (real live features) is research-sized.** Player identity mapping between the fantasy API and the historical feeds may be ambiguous. | P3.1–P3.4 and P3.6–P3.7 ship first and are valuable on their own. `price_prior_v1` stays the explicit default. P3.5 can slip to v1.0.3 without blocking the release; mark the finding "partially closed" if so. |
| **Changing the quota to 6 changes recommendations users have seen.** | Release notes (P9.4). Certification gates assert the configured value equals the official config, so a future API change is caught immediately. |
| **Schema migrations** (`snapshot_game_rules`, the `team_transfers` columns, versioned outcomes) on the user's real DB. | Every migration is versioned, idempotent and covered by a test against a copy of a v1.0.1-shaped DB, built by the v1.0.1 code in a fixture. `elf doctor` reports unresolved backfill rows. Back up `data/euroleague.sqlite3` automatically before the first v1.0.2 migration (`data/backups/pre-1.0.2-<ts>.sqlite3`). |
| **Strict replay conflicts (409) may block edits that "worked" before.** | The error lists the conflicting trades. `discard_conflicting=True` gives a deliberate escape hatch, and it is audited. |
| **The CSP/inline-handler rewrite of a 2,800-line `app.js` could regress the UI.** | P5.2 is done component by component, guarded by the JS harness tests and the static no-inline-handler test. The manual smoke test is in P9.3. |
| **Suite runtime grows** (property tests, certification test). | Use `slow`/`perf` markers. CI runs default + slow on `main` PRs; feature-branch pushes run default only. |
